# App name: decisions

## 2026-11-09 The app is called Spotter

What came up: the app was called "Program", the same word as the thing it tracks.

What I picked: "Spotter". I asked for it directly ("update the app name to be 'Spotter'"). I didn't give a reason.

Scope: only where the app's name shows (landing title and header, login and join headers, PT sidebar, README heading). Page titles that never carried the name stay as they are.
