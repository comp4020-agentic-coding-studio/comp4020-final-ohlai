# Client can hide "Training now": decisions

## 2026-11-08: PT sees that it is hidden, not just nothing

- Came up: when the client hides "Training now", the PT could see either nothing or a message saying it's hidden.
- Options: (a) show nothing, (b) show "Training status hidden by client".
- Picked (b). My reason: otherwise it looks the same as not training and is confusing for the PT.

## 2026-11-08: the control is a toggle switch in the app's theme

- Came up: the Settings checkbox was the browser default.
- Picked: a styled toggle switch using the colour tokens. I asked for it to match the theme of the app.
