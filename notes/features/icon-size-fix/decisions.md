# icon size fix: decisions

## 2026-11-09: make the client nav icons bigger

What came up: I asked for the client bottom nav icons to be bigger.

Options: any size up from the old 22px. 24px is a small bump, 28px is clearly bigger, 32px starts to crowd the 72px links.

Picked: 28px (agent's pick, since I only said "increase"). Easy to change if it looks off.

## 2026-11-09: settings icon a bit bigger, pill smaller

What came up: after seeing 28px, I asked for the settings icon to go up a little and the black pill and white highlight to shrink a little.

Picked (my words gave direction, the agent picked the numbers): settings icon 31px, dashboard stays 28px; links and highlight 72px to 62px wide, 12px to 8px vertical padding; pill padding 6px to 5px. This replaces the "every icon is 28px" from the entry above for the settings icon only.
